# MilkDrop presets

The "Visualizer" view on the Now Playing screen runs these presets in projectM.

They are a selection from projectM's [Cream of the Crop](https://github.com/projectM-visualizer/presets-cream-of-the-crop)
collection (curated by ISOSCELES), from its Hypnotic, Fractal, Geometric, Supernova and
Reaction folders at commit `0180df21f5e0bd39b9060cc5de420ed2f1f9e509`. Only presets that
need no texture files beyond those projectM generates itself were picked, and each was
run in Lio's (OpenGL ES) build: ones that failed to load or rendered black or a flat
colour were left out. File names are `<folder> - <original name>`.

Licensing, as stated in that collection's LICENSE.md: MilkDrop presets were, in almost
all cases, not released under any specific license; each preset author theoretically
holds the copyright, and it is safe to assume them to be in the public domain. Authors
who don't want their presets included can ask for them to be removed.
